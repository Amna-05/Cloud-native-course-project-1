ISSUES HIT AND HOW THEY WERE RESOLVED
--------------------------------------
- ECS tasks not starting (taskArns empty):
  Root cause: ecsTaskExecutionRole trust relationship missing ecs-tasks.amazonaws.com
  Fix: aws iam update-assume-role-policy + aws iam put-user-policy (iam:PassRole)

- ECR had no image on first deploy:
  Root cause: pipeline hadn't run yet, ECS had nothing to pull
  Fix: manual docker build + push to ECR before creating the service

- mypy errors in database.py:
  Root cause: dict type inferred from SQLite branch conflicted with PostgreSQL branch
  Fix: explicit `connect_args: dict[str, Any]` annotation before the if block
